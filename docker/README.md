# Docker Directory

This directory contains Docker-related configurations for the Scientific Home Cluster platform.

## Contents

- Dockerfiles for building container images
- Docker-compose files for multi-container setups
- Configuration files for Docker services

## Usage

To build and run the platform using Docker:
```bash
# Build images
docker-compose build

# Start services
docker-compose up

# Stop services
docker-compose down
```

Refer to individual Dockerfiles and compose files for specific usage instructions.
